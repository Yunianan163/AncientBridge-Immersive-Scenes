## mug_b（直筒款茶杯）接入 —— 第 5 类拆法：**按高度硬切**

- 需求：把 `mug_b.glb`（**直筒款茶杯、没把手**）接进来；贴图**只对红框那一段**（唇边下沿 → 底部）；
  材质是**塑料**；唇边 / 杯口 / 杯底保留。
- 模型：AI 出的**整块软体**（50000 面 / 单连通块 / 零 UV / **正圆截面** ——
  `models:section` 实测每 30° 半径 0.278~0.281 恒定）。虽然也叫「茶杯」，但**不是** `mug_a`
  那种 Max 手工拆好的四件：几何上**只有高度可分**。

### ★ 新技法：`cos=-1` 把 `--extract-region` 当**纯高度切刀**

判定式是 `面法向·axis >= cos`。**`cos=-1` 时恒成立 → 朝向条件失效**，只剩 x/y/z 区间裁剪。
为什么需要它：直筒杯要的是**整圈外壁**，而外壁法向是**水平朝外**的（±x / ±z 各占一半），
**任何单一 `axis` 都圈不全** —— 圈法在这里天生不适用。

```bash
npm run models:fix -- "../文创商品模型/mug_b.glb" --out public/models/products/mug_b.glb \
  --extract-region "node_0=cup_inner;axis=+y;cos=-1;y=0.85~1" \
  --extract-region "node_0=cup_bottom;axis=-y;cos=0.7;y=0~0.08" \
  --rename "node_0=cup_body"
```

- ① 一刀切走「唇边 + 杯口 + 口内壁」**25807 面** → `cup_inner`（保留）。
  切点 y=0.904 **正好是唇边下沿** —— 用 `models:layers --layers 60` 逐层量出来的，
  和用户红框的上边严丝合缝。
- ② 再从剩下的里摘朝下的底 **3628 面** → `cup_bottom`（保留，报「2 块互不相连」= **两级底的真实几何**）。
- 剩下 **23097 面** = `cup_body`，就是红框里那一圈。

⚠️ **多刀会连锁**：每一刀的 `y` 都是相对**「当前那一块」的包围盒**算的，不是原始模型。
第 ② 刀的 `y=0.08` 是在第 ① 刀切完后算的（包围盒已变成 `y 0~0.904`，`0.08 × 0.904 ≈ 0.072`）。
**改了前一刀就得重算后面每一刀。** 这条已写进 skill `references/region-extraction.md`。

⚠️ `cup_body` 里留着一块**看不见的**面：杯底内凹那段斜壁（1127 面、半径 0.21、y 0.002~0.052）。
它是**内向面**，既不在「朝下且 y≤0.08」里、也不在「y≥0.85」的杯口段里，两刀都碰不到。
**它在外壁内侧、任何外部视角不可见**（分色体检图确认过），为它再多拆一个零件不值当。

- **没把手** → 给 `CUP_REGIONS` 的 `handle` 加 `optional: true`，**两个茶杯继续共用同一张表**。

## 新增第 7 档质感：**塑料**

- `finish.ts` 的 `FINISHES` 加 `plastic`：`roughness 0.4` + `clearcoat 0.6 / ccRough 0.18` + `envMapIntensity 0.9`。
- **和陶瓷的区别不在 base 的 roughness，在高光的形状**：陶瓷 `clearcoat 1 / ccRough 0.05`
  = 锐利的镜面小高光；塑料 `clearcoat 0.6 / ccRough 0.18` = **一片油亮的亮带**；
  半哑光是更弱的薄漆层（`0.35 / 0.28`）。三档必须一眼能分。
- 并排对照图 `62-直筒杯质感-塑料vs陶瓷.png` 证明能分辨。
- ⚠️ **`check-export.mjs` 的 clearcoat 断言原来用 `===` 精确比**：glTF 里存 float32，
  `0.6` 读回来是 `0.6000000238418579` → **假失败**。改成 `Math.abs(a-b) < 1e-5`。
  （陶瓷的 `1`、金属的 `0` 恰好精确，所以这个坑一直没暴露。）
- `e2e-finish.mjs` 的 `labels` 加 `'塑料'` → **7 档**（原 6 档）。
