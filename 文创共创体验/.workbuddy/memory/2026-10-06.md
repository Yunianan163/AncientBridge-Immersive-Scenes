# 2026-10-06

## 折扇 fan_a 接入网页端（扇面纸质 · 正反面分别贴图 · 扇骨木质）

- **用户要求**（附红框截图）：把 `文创商品模型/fan_a.glb` 放进网页端；红框部分（扇面）做**纸质**、**正反面能分别贴图**，其余（扇骨/扇柄/扇钉）做**木质**。
- **源文件解剖**：单个 mesh `node_0`（50000 面 / 零 UV / 零贴图 / 单一灰材质 `M_03___Default`）；`node_0` 自身 scale 0.001，父节点 scale 1000 + 平移 `(1.75221, 0, -0.56677)` → **净变换 = 纯平移**，所以 `--extract-region` 的 `center=` 要写**世界坐标**。世界包围盒 `x[1.1821,2.2621] y[0,0.6464] z[-0.6406,-0.5273]`。
- **★ 反推出真正的切分参数**（关键一课）：一开始按「扇面是扇环，得用半径圈」的思路试 `center=1.65831, r=0.4956` → 只出 9383 面，跟原始 16821 对不上。于是写 `fan_refit.py` **复刻 `splitByRegion` 语义做参数反推**，发现**不带半径**的 `axis=+z;cos=0.5;y=0.201~1` 正好 16821 面。正式命令：
  ```bash
  node scripts/fix-model.mjs "../文创商品模型/fan_a.glb" --out public/models/products/fan_a.glb \
    --extract-region "node_0=fan_face_front;axis=+z;cos=0.5;y=0.201~1" \
    --extract-region "node_0=fan_face_back;axis=-z;cos=0.5;y=0.201~1" \
    --material "fan_ribs=wood" \
    --rename "node_0=fan_ribs"
  ```
  产物 `1350.6 KB`，三块面数 **16821 / 15907 / 22150**、包围盒、体积与原始实现**逐字节一致**。
- **两条被证伪的旧认知**：① 「扇面必须用半径圈」——错的，只靠**朝向 ±z + 高度 y** 两刀就够（`y=0.201` = 绝对高度 0.13 ÷ 包围盒高 0.646，正是扇面内弧那条边界）；② 「`--extract-region` 不支持串联」——错的，代码里后一步取 `group.geometry`，**是串联的**。
- **★ z 值不能当判据**：扇面是手风琴式褶皱，按 z 分层会把同一片扇面撕成锯齿裂口（实测废掉一版）。
- **★ 新档 `--material <零件>=wood`**：把木色 + 木质数值**烤进 GLB**。因为网页端颜色一律走**调色板**，「表面质感」档位只改 metalness/roughness/clearcoat、**改不了颜色**。木色 `#A87B4F` → 线性 `[0.3916,0.1981,0.0782]`（`baseColorFactor` 是**线性空间**，先做 sRGB→线性）；`metallic 0`、`roughness 0.7`。
- **★ `wood` 必须与 `keepOriginalParts: ['ribs']` 配对**：只烤不保留 → 被调色板覆盖；只保留不烤 → 灰塑料扇骨。
- **★ roughness 0.48 → 0.7**：扇骨是一堆**法向相近的薄片**，低粗糙度下它们同时把影棚环境那块亮面反射进镜头 → 整簇发白、木色被盖掉（实测）。**改这个数之前先看截图。**
- **★ 不做木纹贴图**：扇骨是放射状细条、UV 走 `planar-z` 只有一个方向，木纹该顺着每根扇骨、硬贴必然横切 → 纯色 + 抛光更像真实竹骨。
- **★ 新档 `paper`（纸质，第 8 档）**：`roughness 0.8 / envMapIntensity 0.6 / sheen 0` + **程序生成的纸纤维法线贴图**（256² / `repeat 9` / `scale 0.3` / `STEEP 1.1`）。为什么必须给纹理：纸与「哑光陶土」单看粗糙度（0.8 vs 0.92）**几乎分不开**，纤维纹才是分界线。做法：600 根方向集中（±16°）的细毛（两端渐细、横向 3 像素高斯衰减）+ 两个八度平滑值噪声（浆块）+ 逐像素毛糙；**确定性伪随机 `mulberry32(0x5f3a91)`**（不能用 `Math.random()`，否则刷新就变、截图没法对比）。`applyWeave` 改名 `applySurfaceNormal`（先 `weave`、再 `paper`）。
- **配置**：`FAN_A_REGIONS` = `face_front` / `face_back`（`paintable`）+ `ribs`（保留）；preset 用 `partFinishes: { face_front:'paper', face_back:'paper' }` + `keepOriginalParts:['ribs']` + `materials` 一条 `print_area`，**故意不写顶层 `finish`**（锁住质感选择器，与团扇同思路）。
