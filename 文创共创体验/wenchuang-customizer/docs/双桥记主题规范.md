# 「双桥记」古风主题规范

> 这个定制器的视觉主题取自项目讲述的**两座明代古桥**。
> 本文说清三件事：**为什么是这些颜色**、**主题代码放在哪儿**、**改的时候要动哪一处**。

---

## 一、主题来源（史实）

### 苏州 · 昆山周庄双桥（钥匙桥）

- 由**世德桥**（石拱桥，东西向横跨南北市河）与**永安桥**（石梁桥，南北向平架于银子浜口）组成。
  两桥东北堍纵横相接，**一圆一方、一横一竖**，桥洞交叠形似旧时钥匙，故俗称「钥匙桥」。
- 始建于**明万历年间（1573—1619）**：世德桥由里人**徐松泉、徐竹溪**出资，永安桥由里人**徐正吾**出资。
  清乾隆三十年（1765）两桥俱重修，道光二十三年（1843）里人捐资重建。
- 世德桥长 16 米、宽 3 米、跨径 5.9 米；永安桥长 13.3 米、宽 2.4 米、跨度 3.5 米。桥栏皆以**麻条石**垒砌。
- 1984 年旅美画家**陈逸飞**以双桥为蓝本创作油画《故乡的回忆》，周庄由此名扬海内。
  2006 年列为江苏省文物保护单位。

### 贵州 · 黔南福泉葛镜桥（豆腐桥）

- 横跨**麻哈江**（洒金谷段犀江），**二墩三孔**石拱桥，长 52.7 米、宽 8.5 米、高 23 米。
  「桥在绝壁之上起拱，借江心一礁石下脚」，是**变截面圆弧尖拱**的典型代表。
- 平越（今福泉）人**葛镜**倾尽家资，前后三十余年、**三毁三建**，
  万历四十六年（1618）终于成桥，次年葛镜辞世。初名「太平桥」。
- 云贵总督**张鹤鸣**改题今名并撰《葛镜桥碑记》；**明神宗御赐「义垂千古」匾额**。
  民间因「张三丰点豆腐为石」的传说，俗称「豆腐桥」。
- 2006 年国务院公布为**第六批全国重点文物保护单位**。
  茅以升誉之为「西南桥梁之冠」，留下「北有赵州桥，南有葛镜桥」之说。

> ⚠️ 节庆文案、页面题跋、桥志卡里出现的年代 / 尺寸 / 人名，都以本节为准；
> **不要为了让文案好看而改动数字**。这些内容同时出现在
> `src/components/BridgeNotes.tsx`（桥志卡）与 `src/components/BridgeBackdrop.tsx`（底部题跋）。

## 二、为什么是这些颜色

两桥的**公共语汇**才是主题的取色依据 —— 这是「融合」而不是「拼贴」的关键：

| 两桥的共同点 | 得出的色 | 变量 | 值 |
| --- | --- | --- | --- |
| 同为**青石**砌筑（花岗石 / 石灰岩） | 青石 | `--stone` | `#6d7a76` |
| 同属**明万历**，同见题刻 / 碑记 / 匾额 | 朱砂（印色） | `--cinnabar` | `#a8352b` |
| 一跨江南**市河**、一跨黔中**麻哈江** | 水色 | `--water` | `#5b8a91` |
| 一在**水乡**、一在**绝壁峡谷** | 山色 / 黛瓦 | `--mountain` `--tile` | `#5a6a50` `#454a51` |
| 都是**纸本拓片**式的文物 | 宣纸 / 墨 | `--paper` `--ink` | `#ece3d0` `#2b2721` |

差异（江南的黛瓦粉墙 vs 黔中的绝壁峡谷）放在**装饰层的左右两半**里表达，
不掺进主色板 —— 主色板一杂，整个界面就不像「一套」了。

### 字体策略

```css
--font-song: 'Noto Serif SC', 'Source Han Serif SC', 'Songti SC', 'STSong', 'SimSun', '宋体', serif;
--font-kai:  'Kaiti SC', 'STKaiti', 'KaiTi', '楷体', 'FangSong', '仿宋', serif;
```

- **正文用宋、标题与印章用楷**。
- ⚠️ **只用系统自带字体，不引任何网络字体**（`src/index.css` 原先 `@import` 的 Google
  Fonts Inter 已删）。理由与 `three/studioEnv.ts` 拒用 CDN HDRI 完全一致：
  **这个项目要求离线可用**，网络字体一拉不到就 FOUT 成默认无衬线，「古风」当场塌掉。

## 三、代码分工（改主题只需要动一处）

| 文件 | 职责 | 改主题要动它吗 |
| --- | --- | --- |
| **`src/theme.css`** | **主题层**：`:root` 变量（纸 / 墨 / 朱砂 / 青石 / 水 / 山 / 黛瓦）、字体、纸纹、回纹底纹，以及覆盖底座配色的全部规则 | ✅ **只改这里** |
| `src/App.css` | 底座**结构层**：布局、间距、状态类名、响应式断点 | ❌ 不要在这儿找颜色 |
| `src/studio.css` | 工作台**结构层**：同上 | ❌ |
| `src/index.css` | 最基础重置（`color-scheme`、`body` 底色） | 偶尔 |
| `src/components/BridgeBackdrop.tsx` | 底部水墨长卷（两桥）+ 回纹角饰 + 题跋 | 加/改装饰时 |
| `src/components/BridgeNotes.tsx` | 工作台里的「桥志」折卡（两桥史实） | 改文案时 |

### 加载顺序是**关键**

`src/App.tsx`：

```ts
import './App.css'
import './studio.css'
import './theme.css'   // ← 必须最后：靠层叠顺序覆盖上面两个底座文件里的暗色玻璃配色
```

⚠️ **`theme.css` 一旦被提到前面，整个界面会退回暗色玻璃**（原配色会重新压过主题）。
另外 `App.css` / `studio.css` 里那套 `rgba(0,0,0,.45)` + 白色 15% 描边是**主题之前的原始外观**，
文件头已加注释说明，不要照着它去改颜色。

### 为什么不做成「另一个 CSS 文件覆盖」而在原文件里改

底座那两个文件里的硬编码颜色有 20 多种写法（`rgba(255,255,255,.06/.1/.15/.2/.3…)`、
`rgba(0,0,0,.45/.55/.3/.35)`…），逐条 `replace_all` 既易漏又难回滚。
现在这样：**结构层原样不动、视觉全部集中在 theme.css**，
想换主题（比如以后做「青花」或「朱漆」版）只需换掉一个文件。

## 四、装饰层构图约束（⚠️ 改面板宽度或画布比例时必看）

底部那条长卷画在**画布可见区**里，而画布左右两侧被两块面板压着：

| 面板 | 宽度 | 位置 |
| --- | --- | --- |
| 左 · 配色（`.color-controls`） | 280px（≤768px 时改成底部抽屉） | `left: 0` |
| 右 · 文创定制（`.studio-dock`） | 350px | `right: 1rem` |

> 📌 2026-10-09：原来的「器物」浮动面板（`.model-selector`，画布左上角 `left: 350px`）
> 已并进**左栏顶部**，中央画布不再被它遮挡。面板宽度没变，所以上表的可见区换算仍然有效。

换算到长卷的 viewBox（`0 0 1200 200`，`preserveAspectRatio="xMidYMax slice"`）：

| 窗口宽 | 缩放 | 真正露出来的 viewBox x 区间 |
| --- | --- | --- |
| 1280 | 1.28 | **319 ~ 814** |
| 1440 | 1.44 | **294 ~ 846** |
| 1920 | 1.60 | 175 ~ 971 |

所以：**两座桥全部排在 `x 320 ~ 820` 之间**，
这条带子以外只放远山、崖壁、水波这些「裁掉也不可惜」的东西。
竖向同理，全部压在 `y ≥ 62`，超宽屏（2560）从顶部裁下来也切不到主体。

- ⚠️ `preserveAspectRatio` 必须是 **slice**：`meet` 在宽屏下会按高度收缩、左右留白，水波会断。
- **改这两块面板的宽度、或改 `.bridge-scroll` 的高度之后，必须重新截一张 1440 宽的图核对**
  （命令见下），别只看代码。

## 五、画底（背景色）与「墨色自动翻转」

工具栏「配置 → **画底**」里有 8 个预设，取的都是两桥现场的颜色：

| 预设 | 值 | 说明 |
| --- | --- | --- |
| 松墨 | `#34352d` | 深底偏暖的墨绿（2026-10-09 新增；原来是偏冷的「墨青 `#3f4a4c`」，因画心在暖宣纸上像挖了个冷色的洞而换掉） |
| 青石 | `#4e5350` | 两桥同为青石砌筑 |
| 暮山 | `#4a4249` | 黔中峡谷 |
| 赭石 | `#5c4a3d` | 夯土崖壁 |
| 黛瓦 | `#454a51` | 江南屋面 |
| 焦墨 | `#2b2721` | 最深 |
| 宣纸 | `#ece3d0` | 浅底，像把器物摆在册页上 |
| **绢本（默认）** | **`#e0d3b6`** | 浅底偏黄，即宣纸/绢本的画底 |

⚠️ **本表必须与 `src/components/Toolbar.tsx` 的 `BG_PRESETS` 逐字一致**（上表值取自该数组 `:31-40`）。
八格要整体保持**暖**：页面本身是宣纸底，画底一旦偏冷蓝，画心就会像在暖纸中间挖了个冷色的洞。

默认画底是**绢本 `#e0d3b6`**（2026-10-09 由松墨 `#34352d` 改为绢本），**三处必须逐字同色**：

1. `src/components/Scene.tsx` 的 `useState('#e0d3b6')`
2. `src/components/Toolbar.tsx` 的 `BG_PRESETS` 里「绢本」
3. `src/theme.css` 的 `--scene-bg`

⚠️ **画布铺满视口，画底色会以约 8% 透光染遍整页** —— 所以「换画底」= 换整页纸色，
面板纸色会跟着位移（面板纸位移 ≈ 画底位移 × 0.08），这是「面板跟着变暗」的解释。

⚠️ **装饰线的墨色会跟着翻转**：`Scene.tsx` 按画底明暗（Rec. 709 相对亮度，阈值 0.55）
把 `--scene-ink` 写到 `:root` 上 ——
深底给 `#d3c7ab`（淡墨）、浅底给 `#4a4436`（浓墨）。
`BridgeBackdrop` 是 `App` 的兄弟节点、拿不到 `Scene` 的 props，所以只能走 CSS 变量。
**没有这一步，用户一切到「宣纸」那条长卷就会整个消失。**

底部题跋则做成**墨底签条**（`rgba(26,31,31,.5)` 底 + 米色字），
理由相同：纯文字在浅底上会彻底看不见。

## 六、新增的类名 / 组件（都带前缀，不会和旧的撞）

| 名字 | 位置 | 是什么 |
| --- | --- | --- |
| `.toolbar-plaque` `.toolbar-seal` `.toolbar-title-sub` | Toolbar | 题签主体、朱砂印、副题 |
| `.bg-presets` `.bg-preset` `.bg-presets-label` | Toolbar | 「画底」预设色块 |
| `.bridge-backdrop` `.bridge-scroll` `.bridge-corner` `.bridge-caption` | BridgeBackdrop | 装饰层四个部分 |
| `.bridge-notes*` | BridgeNotes | 桥志卡 |

⚠️ 按项目既有约定：**新增类名前先 `grep src/`**。
`.studio-chip` / `.studio-chips` 是 AiPanel 提示词按钮的、
`.studio-region-chip` 是部位按钮的，谁都不能复用。

### 题签上的合体符号

`.toolbar-seal` 里那个图形是两桥的合体：
**一条桥面之下，圆拱（世德桥）+ 方洞（永安桥）+ 尖拱（葛镜桥）并列**。
同一套语义在底部长卷里展开成左右两半。改动徽记时保持这三个母题。

## 七、怎么验证改动

```bash
npm run dev:all                                    # 起前后端
node scripts/e2e-shot.mjs "70-古风主题-总览" --wait 15000   # 拍一张 1440×900 的整页
```

- 出来的图在 `docs/联调截图/`。**看三个地方**：
  ① 底部两座桥有没有被面板压住；② 题跋签条读不读得清；③ 面板底色是不是宣纸而不是暗玻璃。
- 改过 `Toolbar` / `App.tsx` 的 DOM 之后，跑一遍断言确认没打坏功能：

```bash
npm run e2e:paint -- --model mug_a     # 17 项（会用 .studio-region-chip / .model-dropdown 等选择器）
npm run e2e:finish                     # 8 档质感
```

⚠️ e2e 脚本大量依赖**类名与按钮文案**（`.studio-region-chip`、`.finish-chip`、
`.studio-drop input[type=file]`、`aria-label*=auto rotate`、按钮文字「下载 GLB」）。
改主题时**可以改颜色和字体，不要改这些**；**`aria-label` 一律保持原样**。
