# 语音对话功能集成说明

## 文件结构

```
网站部分/
├── index.html              # 主页面（已添加语音对话面板HTML）
├── main.js                 # 主脚本（添加了面板控制函数）
├── style.css               # 样式（已添加语音对话面板样式）
├── voice-dialog.js         # 新的语音对话模块（移植自RealtimeDialog-Web）
└── ...

RealtimeDialog-Web/       # 原始语音对话文件（保持不变）
├── app.js
├── AudioPlayer.js
├── AudioRecorder.js
├── config.js
├── events.js
├── protocol.js
└── RealtimeDialogClient.js
```

## 集成方式

1. **HTML面板**：在 index.html 中添加了 `voice-dialog-panel` 面板
2. **样式**：在 style.css 中添加了语音对话相关样式
3. **模块引用**：使用 ES6 模块方式引用 RealtimeDialog-Web 的功能
4. **初始化**：voice-dialog.js 作为模块入口，导入 RealtimeDialog-Web 的所有功能

## 使用流程

```
1. 用户完成任务解锁机器人
2. 点击 "进入机器人语音对话" 按钮
3. 观看介绍视频
4. 视频播放结束 → 自动显示语音对话面板
5. 点击 "开始对话" 连接服务器
6. 进行语音交流
```

## 测试步骤

1. 确保服务器运行：`node server.js`
2. 刷新网页：`http://127.0.0.1:8082`
3. 完成任务流程解锁机器人
4. 点击语音对话按钮，观看视频
5. 视频结束后应显示右下角语音对话面板

## 注意事项

- 语音对话功能需要麦克风权限
- 确保服务器语音代理已启用
- 使用 HTTPS 或 localhost 才能使用麦克风
