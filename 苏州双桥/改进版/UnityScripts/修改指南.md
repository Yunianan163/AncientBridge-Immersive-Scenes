# Unity 代码修改指南

## 需要修改的文件

根据你的场景截图，主要修改以下文件之一：

### 方案一：修改 WebSocketManager（推荐，如果它负责接收消息）

找到你的 `WebSocketManager.cs` 文件，添加以下代码：

```csharp
using UnityEngine;

public class WebSocketManager : MonoBehaviour
{
    // ====== 新增：引用机器人和动画控制器 ======
    [Header("机器人动画控制")]
    public Animator robotAnimator;  // 拖拽机器人的 Animator 到这里
    
    // 节流时间记录
    private float lastListenNodTime = -999f;
    private float lastTalkTime = -999f;
    private System.Random random = new System.Random();
    
    // 冷却时间配置
    public float listenNodCooldown = 1.2f;
    public float talkGestureCooldown = 1.0f;
    // ============================================

    // ... 你现有的代码 ...

    // ====== 修改/添加：消息接收处理 ======
    void OnMessage(string message)  // 或者你的消息接收回调方法名
    {
        Debug.Log($"[WebSocket] 收到消息: {message}");
        
        // 解析消息
        try
        {
            // 简单提取 type 和 from 字段
            string type = ExtractJsonValue(message, "type");
            string from = ExtractJsonValue(message, "from");
            
            // 只处理来自 web 的消息
            if (from != "web") return;
            
            Debug.Log($"[WebSocket] 处理消息类型: {type}");
            
            // 处理动画消息
            switch (type)
            {
                case "robotListenNod":
                    TriggerListenNod();
                    break;
                    
                case "robotAfterUserNod":
                    TriggerAfterUserNod();
                    break;
                    
                case "robotTalkStart":
                    string trigger = ExtractJsonValue(message, "trigger");
                    TriggerTalk(trigger);
                    break;
                    
                case "robotTalkEnd":
                    // AI 停止说话，动画会自动返回
                    Debug.Log("[RobotAnimation] AI 停止说话");
                    break;
                    
                case "robotConversationReady":
                    Debug.Log("[RobotAnimation] 语音对话已就绪");
                    break;
            }
        }
        catch (System.Exception e)
        {
            Debug.LogError($"[WebSocket] 处理消息失败: {e.Message}");
        }
        
        // ... 你现有的其他消息处理 ...
    }

    // ====== 新增：动画触发方法 ======
    
    /// <summary>
    /// 倾听点头 - 用户开始说话时
    /// </summary>
    void TriggerListenNod()
    {
        if (Time.time - lastListenNodTime < listenNodCooldown) return;
        if (robotAnimator == null) return;
        
        lastListenNodTime = Time.time;
        robotAnimator.SetTrigger("ListenNod");
        Debug.Log("[RobotAnimation] 触发倾听点头: ListenNod");
    }
    
    /// <summary>
    /// 回应点头 - 用户说完话后
    /// </summary>
    void TriggerAfterUserNod()
    {
        if (robotAnimator == null) return;
        
        robotAnimator.SetTrigger("AfterUserNod");
        Debug.Log("[RobotAnimation] 触发回应点头: AfterUserNod");
    }
    
    /// <summary>
    /// 说话动画 - AI开始说话时
    /// </summary>
    void TriggerTalk(string triggerName)
    {
        if (Time.time - lastTalkTime < talkGestureCooldown) return;
        if (robotAnimator == null) return;
        
        lastTalkTime = Time.time;
        
        // 如果没有指定 trigger，随机选择
        string actualTrigger = string.IsNullOrEmpty(triggerName) 
            ? (random.Next(2) == 0 ? "Talk1" : "Talk2")
            : triggerName;
        
        robotAnimator.SetTrigger(actualTrigger);
        Debug.Log($"[RobotAnimation] 触发说话动画: {actualTrigger}");
    }
    
    /// <summary>
    /// 简单的 JSON 值提取（不依赖外部库）
    /// </summary>
    string ExtractJsonValue(string json, string key)
    {
        string pattern = $"\"{key}\"\\s*:\\s*\"";
        int startIndex = json.IndexOf(pattern);
        
        if (startIndex < 0) 
        {
            // 尝试不带引号的值
            pattern = $"\"{key}\"\\s*:\\s*";
            startIndex = json.IndexOf(pattern);
            if (startIndex < 0) return "";
            
            startIndex += pattern.Length;
            int endIndex = json.IndexOfAny(new char[] { ',', '}', ' ' }, startIndex);
            if (endIndex < 0) endIndex = json.Length;
            
            return json.Substring(startIndex, endIndex - startIndex).Trim().Trim('"');
        }
        
        startIndex += pattern.Length;
        int endQuoteIndex = json.IndexOf("\"", startIndex);
        if (endQuoteIndex < 0) return "";
        
        return json.Substring(startIndex, endQuoteIndex - startIndex);
    }
}
```

---

## 在 Unity Inspector 中的配置

修改代码后，选中 **WebSocketManager** 游戏对象，在 Inspector 中：

1. 找到 **Robot Animator** 字段
2. 将场景中的 **机器人模型** 拖拽到这个字段上
3. （可选）调整冷却时间：
   - **Listen Nod Cooldown**: 1.2（默认）
   - **Talk Gesture Cooldown**: 1.0（默认）

---

## 验证步骤

1. 保存代码并返回 Unity
2. 确保没有编译错误
3. 运行场景
4. 打开浏览器进入语音对话
5. 点击"开始对话"按钮
6. 开始说话，观察机器人是否有点头动作

如果动画不触发，检查 Console 窗口是否有以下日志：
- `[WebSocket] 收到消息: ...`
- `[RobotAnimation] 触发倾听点头: ListenNod`

如果没有收到消息，检查 WebSocket 连接是否正常。
