## 项目跑不起来：`python` 命令指向 Microsoft Store 占位符

**现象**：`E:\葛镜桥高斯\最新模型\web>python tools/serve.py` 报
`Python was not found; run without arguments to install from the Microsoft Store`。

**根因**：`AppData\Local\Microsoft\WindowsApps\` 下有两个系统生成的「应用执行别名」
占位符 `python.exe` / `python3.exe`，都指向 `AppInstallerPythonRedirector.exe`。
该目录在 PATH 中，而真正的 Python 安装目录 **不在** PATH 里（只有其 `Scripts`
子目录在），所以 `python` 命中的是跳板。

**本机可用解释器**（实测）：
- `py -3` → `C:\Windows\py.exe`，解析到 Python 3.10.11 ✓（最省事的办法）
- 完整路径 `C:\Users\32686\AppData\Local\Programs\Python\Python310\python.exe` ✓
- 托管 `C:\Users\32686\.workbuddy\binaries\python\versions\3.13.12\python.exe` ✓

**服务器本身完全正常**（用 Python 内部直连实测，非 curl）：
index.html / js/*.js / heightmap.json / scene.ply 全部 200；
`.js` 返回 `text/javascript`（serve.py 的 extensions_map 覆盖生效）；
`.ply` 返回 `application/octet-stream`，Content-Length 259,918,795；
COOP=same-origin、COEP=require-corp 均已正确下发。

> 注意：本环境里用 `curl` 测 localhost 会被沙箱代理拦截，返回伪造的
> `Content-Type: text/plain` / `upstream connect failed`，会误判成服务器有问题。
> **验证本地 HTTP 必须改用 Python 的 `http.client` 直连。**
